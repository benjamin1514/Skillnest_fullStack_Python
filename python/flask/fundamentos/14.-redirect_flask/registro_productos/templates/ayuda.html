Conceptos clave de Flask y HTTP

1. ¿Qué es una solicitud GET?

Se utiliza para solicitar o consultar información al servidor. No debe modificar datos y los parámetros suelen viajar visibles en la URL.

2. ¿Qué es una solicitud POST?

Se utiliza para enviar datos al servidor para ser procesados (por ejemplo, guardar un nuevo producto en base de datos). Los datos viajan ocultos en el cuerpo de la petición (body).

3. ¿Para qué sirve redirect()?

Indica al navegador del usuario que debe hacer una nueva solicitud a una ruta diferente. Permite aplicar el patrón PRG (Post/Redirect/Get) para evitar el envío duplicado de formularios al recargar la página.

4. ¿Por qué request.form no está disponible después de la redirección?

El protocolo HTTP es sin estado (stateless). Una redirección fuerza al navegador a hacer una segunda solicitud independiente de tipo GET, por lo que los datos del formulario enviados en la primera solicitud POST se pierden en el camino.
